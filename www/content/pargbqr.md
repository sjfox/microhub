The **parGBQR** model is a parametric variant of newGBQR. It keeps the year-round feature set from newGBQR, including cyclic week-of-year terms, empirical peak timing, recent trend features, rolling summaries, and horizon interactions.

Like newGBQR, parGBQR predicts future change on the centered fourth-root transformed incidence scale. The central model therefore learns the same transformed delta target as newGBQR. This applies when "Data Type" is set to Counts. When "Data Type" is set to Proportion (0-1), parGBQR instead transforms the response with a logit, bounding forecasts to (0, 1); only mean-centering is applied (no magnitude rescale, since logit values are already roughly scale-free), and the population/rate-per-100k pathway is disabled, since it does not apply to values that are already proportions.

Instead of fitting one LightGBM quantile model for each requested quantile, parGBQR fits one LightGBM median quantile model per bag and estimates residual uncertainty from empirical training residuals on the transformed delta scale. For each forecast row, it first uses residuals with the same forecast horizon and nearby target week of year, then falls back to broader residual pools when there is not enough local history. The target-week pooling uses a 53-week circular calendar, so week 53 remains distinct and is treated as close to week 1.

Requested quantiles are generated from that centered empirical residual distribution and then converted back to the same count-scale output format as newGBQR. The tradeoff is that uncertainty is calibrated from observed residual pools rather than learned directly for each quantile.
