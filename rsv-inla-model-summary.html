INFLAenza Model Comparison for Microhub

Model-specific comparison of the current Microhub INFLAenza implementation against the RSV, COVID, FluSight, and Metrocast forecasting efforts.

Prepared August 27, 2026

Executive Summary

Microhub currently has a generalized INFLAenza count model. The four US forecasting efforts use related INLA ideas, but they add task-specific likelihoods, spatial structures, holiday effects, seasonal grouping, and direct state/national modeling. The cleanest path is to keep Microhub's generic model as the default and add named model presets for each forecasting effort.

Current Microhub INFLAenza Model

For multiple target groups, Microhub currently fits approximately:

value ~ 1 + target_group +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE) +
  f(t, model = "ar1", group = group_idx,
    control.group = list(model = "exchangeable"))

For a single target group, Microhub fits:

value ~ 1 +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE) +
  f(t, model = "ar1")

In plain terms: Microhub uses a Poisson count model with a shared seasonal curve and a short-term AR1 trend. For multiple groups, the short-term trend is correlated across groups using an exchangeable structure.

RSV Forecasting Models

RSV Hospitalizations

Y ~ 1 + location_name +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE) +
  f(t,  is_state, model = "ar1") +
  f(t3, is_nat,   model = "ar1") +
  f(t2, is_state, model = "ar1", group = iloc,
    control.group = list(model = "exchangeable"))

This differs from Microhub because it uses a censored Poisson response, models national and state rows directly, and uses separate AR1 components for state and national trends.

RSV ED Proportions

count ~ 1 + abbreviation +
  f(ixmas, model = "rw1", scale.model = TRUE) +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE) +
  f(t, model = "ar1") +
  f(iloc, model = "besagproper", graph = graph,
    group = t2, control.group = list(model = "ar1"))

This differs from Microhub because it uses a beta/logit proportion model, includes a Christmas-distance effect, and uses a spatial-temporal Besagproper effect instead of exchangeable grouping.

COVID Forecasting Models

COVID Hospitalizations

count ~ 1 + abbreviation +
  f(ixmas, model = "rw1", scale.model = TRUE) +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE,
    control.group = list(model = "iid")) +
  f(t, model = "ar1") +
  f(iloc, model = "besagproper", graph = graph,
    group = t2, control.group = list(model = "ar1"))

COVID ED Proportions

count ~ 1 + abbreviation +
  f(ixmas, model = "rw1", scale.model = TRUE) +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE,
    control.group = list(model = "iid")) +
  f(t, model = "ar1") +
  f(iloc, model = "besagproper", graph = graph,
    group = t2, control.group = list(model = "ar1"))

The hospitalization and ED proportion formulas are similar, but the ED target requires beta/logit handling. Compared with Microhub, COVID mainly needs the Christmas effect, main AR1 plus spatial-temporal Besagproper structure, and correct beta/logit support for proportions.

FluSight Forecasting Models

FluSight Hospitalizations

count ~ 1 + abbreviation + early_covid +
  f(ixmas, model = "rw1", scale.model = TRUE) +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE,
    group = season_group, control.group = list(model = "iid")) +
  f(t, model = "ar1") +
  f(iloc, model = "besagproper", graph = graph,
    group = t2, control.group = list(model = "ar1"))

FluSight ED Proportions

prop ~ 1 + abbreviation + early_covid +
  f(ixmas, model = "rw1", scale.model = TRUE) +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE,
    group = season_group, control.group = list(model = "iid")) +
  f(t, model = "ar1") +
  f(iloc, model = "besagproper", graph = graph,
    group = t2, control.group = list(model = "ar1"))

FluSight is the most model-rich state-level implementation. It adds early-COVID adjustment, Christmas-distance effects, separate seasonal curves by geography group, and a spatial-temporal Besagproper effect. The ED model also needs beta/logit proportion support.

Metrocast Forecasting Models

Single-Metro States

observation ~ 1 +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE) +
  f(t, model = "ar1")

Multi-Metro States

observation ~ 1 + location +
  f(epiweek, model = "rw2", cyclic = TRUE, scale.model = TRUE) +
  f(t2, model = "ar1", group = iloc,
    control.group = list(model = "exchangeable"))

Metrocast is closest to Microhub's generic structure, but it fits beta/logit proportion models separately by state. For multi-metro states, it uses an exchangeable grouped AR1 without the extra main f(t, model = "ar1") term.

Recommended Microhub Model Presets

Preset Forecasting Effort Core Model Changes
generic_count Microhub default Keep current Poisson seasonal + AR1 model.
rsv_hospitalizations RSV Censored Poisson; direct state/national modeling; separate AR1 components.
rsv_ed_proportion RSV Beta/logit; Christmas effect; spatial-temporal Besagproper effect.
covid_hospitalizations COVID Poisson; Christmas effect; main AR1; spatial-temporal Besagproper effect.
covid_ed_proportion COVID Beta/logit version of the COVID spatial-temporal model.
flusight_hospitalizations FluSight Early-COVID effect; Christmas effect; season-group-specific seasonality; spatial-temporal Besagproper effect.
flusight_ed_proportion FluSight Beta/logit version of the FluSight state-level model.
metrocast_ed_pct Metrocast Beta/logit; per-state fitting; single-location and multi-location formula branches.

Core Microhub Refactor Needed

  1. Make INLA formula construction configurable rather than hard-coded.
  2. Add correct beta/logit likelihood support and posterior sampling with plogis().
  3. Add censored Poisson support for RSV hospitalization forecasts.
  4. Add spatial graph support for besagproper models.
  5. Add model-generated covariates such as ixmas, season_group, early_covid, is_state, and is_nat.
  6. Allow presets to choose whether aggregate rows are modeled directly or reconstructed after sampling.
