The **newGBQR** model is a year-round version of GBQR designed for direct comparison with the original GBQR implementation. It keeps the gradient-boosted quantile regression framework, but removes fixed in-season and out-of-season windows so forecasts can be produced from any week of the year.

Instead of relying on the assigned seasonality Zone to define the peak, newGBQR estimates a peak week empirically from the uploaded historical data. It also uses cyclic week-of-year features, recent trend features, rolling summaries, and LightGBM quantile models to produce probabilistic forecasts across the requested horizons.

By default, when "Data Type" is set to Counts, the LightGBM quantile models predict future change on a centered fourth-root transformed incidence scale (a Freeman-Tukey-style transform), and results are rescaled using any uploaded `population` column to convert between raw counts and population rates. When "Data Type" is set to Proportion (0-1), the response is transformed with a logit instead, which bounds forecasts to (0, 1); only mean-centering is applied to the logit values (no magnitude rescaling, since logit-scale values are already roughly scale-free), and the population/rate-per-100k pathway is disabled, since it does not apply to values that are already proportions.
